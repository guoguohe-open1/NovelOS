# 产品范围与验收

## 1. 目标与使用场景

NovelOS 服务个人长篇网文作者，首先覆盖玄幻题材。作者希望在大量章节之间保留人物状态、设定和伏笔，同时能够修改 AI 的方向、正文与结论。系统需要降低重复整理和上下文准备的成本，并让每次生成有来源、每次接纳可追溯。

典型工作方式是：作者给出创意与约束，维护少量关键资产和章节纲，系统生成候选稿与审阅意见，作者验收后才更新正式剧情。作者可以选择完全手写，再让系统提取待验收的记忆。

产品不以“Agent 数量”衡量价值。优先验证作者能否理解生成依据、发现冲突、保留修改并继续创作。

## 2. 阶段边界

| 阶段 | 包含 | 明确不包含 |
| --- | --- | --- |
| MVP | 单作者私有本地运行；玄幻规则包；项目/资产/卷章管理；规划提案；单章生成与人工稿审阅；版本历史；人工验收；结构化记忆与摘要检索；Markdown 导出 | 公开部署、多用户、自动连写整卷、市场扫描、图谱编辑、任意代码插件、向量数据库、自动循环改稿 |
| 长篇验证 | 使用 MVP 按章完成至少 10 万汉字的实验作品，记录一致性、人工干预与成本 | 将一次成功实验推断为百万字稳定能力 |
| 后续扩展 | 都市规则包、风格模板、语义检索、关系/剧情图、导演计划、受控批处理、百万字实验 | 未经单独设计就提供公网多租户服务 |

MVP 不依赖 Redis、Qdrant、LangGraph 或 React Flow。保留接口位置，出现实际需要时再引入；具体理由见 [决策记录](decisions.md)。

## 3. 用户任务与完成标准

| ID | 作者要完成的事 | MVP 行为与验收 |
| --- | --- | --- |
| P01 | 建立创作项目 | 输入标题、创意、风格参数和玄幻规则包；刷新后仍可读取；规则包 ID 与版本固定 |
| P02 | 管理设定 | 创建/编辑人物、世界规则、事件、伏笔；字段有校验；保存正式资产后递增正式修订 |
| P03 | 准备规划 | 创建卷章和章节纲；也可让 Planner 生成设定/大纲提案；查看后整批接纳或拒绝，不能自动覆盖 |
| P04 | 生成一章 | 指定章节、目标长度、预算；页面立即获得任务 ID；离开页面再回来仍可查看进度和结果 |
| P05 | 保留人工编辑 | 保存正文产生新版本；遇到其他标签页的修改提示冲突；AI 候选稿不会覆盖编辑区 |
| P06 | 审阅并验收 | 同屏查看候选正文、问题与记忆变更；接纳后正文和记忆一起生效；拒绝后正式数据不变 |
| P07 | 处理失败和过期 | 能看到失败类别、已发生的用量、重试/取消入口；过期候选可读，但不能直接接纳 |
| P08 | 继续下一章 | 上下文包含有效正式设定、前章摘要和未回收伏笔，并标注来源；其他项目与后续章节信息不能混入 |
| P09 | 备份和导出 | 按章序导出已验收 Markdown 正文；有数据库备份和恢复说明；草稿与正式正文范围可辨认 |

“重写”在 MVP 中生成新的候选版本，作者再比较和接纳；局部选区流式改写、自动合并、分支创作后置。

## 4. 核心产品规则

1. **人工决定正式剧情**：模型输出、批评分数与事实提取均为建议，自动任务没有最终验收权。
2. **改动可追溯**：版本记录作者类型、来源任务、提示词/规则包/模型版本；原文不被就地覆盖。
3. **记忆有来源**：每条正式记忆关联已验收正文或资产版本；未验收稿不能污染下一章。
4. **过期不能静默应用**：任务基于旧正式修订或旧草稿生成时，提示冲突并要求重跑审阅或重新生成提案。
5. **长流程可中断**：任务离开页面继续存在；取消停止后续步骤，保留已经发生的用量和候选记录。
6. **用户可判断成本**：提交前设置上限；完成后显示可获得的 token 用量和费用估算依据，未知费用显示未知。

## 5. 质量目标

MVP 发布门槛是 P01–P09 可重复演示，且 [验证策略](validation.md) 中的数据一致性、隔离和恢复场景通过。普通 CRUD 不等待模型响应；模型任务通过异步接口返回和轮询，具体性能基线在实际环境记录后设定。

目标长度是生成约束，不是模型保证。UI 明示实际汉字数与目标偏差；确定性规则检查必需字段和禁用设定，Critic 的评分是编辑参考，不代表真实读者留存或商业效果。

10 万字实验按明确的汉字计数规则统计已验收正文，另行报告标点在内的总字符数、章节数、实际模型用量、总耗时和人工干预。文笔、人物动机与伏笔回收需要作者评审，不用自评模型分数代替。

## 6. 暂定前提与后续决策

- 首个部署场景是作者个人电脑/私有环境，默认只监听回环地址。不具备身份认证与授权前，不支持公网暴露。
- 首个真实模型适配器在实现时根据可用供应商确定；先交付可确定性运行的假模型，不读取现有 `.env` 推断密钥。
- 中文 Markdown 是正文的初始交换格式；富文本、DOCX、电子书排版后置。
- 章节长度、风格参数和预算由作者设置；实际默认值在真实写作实验中调整，文档不把任意默认值包装成已验证结论。
